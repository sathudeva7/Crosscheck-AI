# Pinned exactly, not loosely.
#
# The agent is built against a specific LangChain and LangGraph, and both have
# changed their APIs across major versions. An unpinned install resolves to
# whatever is newest on the day the host builds, which is how an app that runs
# on a laptop fails to start in production with an import error.
#
# Verified against Python 3.13.
