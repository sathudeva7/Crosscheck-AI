# Health Icons

The SVG files in this directory are from **Health Icons**, a volunteer project
that publishes icons for public-health software as a global good.

- Source: <https://healthicons.org>
- Repository: <https://github.com/resolvetosavelives/healthicons>
- Licence: **CC0 1.0 (public domain)** — free for commercial or personal use,
  no attribution required, and free to modify.

They were chosen over general-purpose illustration libraries because they are
drawn for medical software specifically — a blister pack, a prescription
document, a cardiogram — rather than being generic shapes standing in for
medical ideas. The outline set is used, which is stroked rather than filled and
so sits correctly alongside the blueprint components in `industry.css`.

Every file carries `fill="currentColor"`, so each icon takes its colour from
the element it is rendered into and needs no editing to match the accent.
